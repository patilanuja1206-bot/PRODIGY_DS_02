# PRODIGY_DS_02

## Task 2 - Data Cleaning & Exploratory Data Analysis (EDA)
**Internship:** Prodigy InfoTech - Data Science Track

### Objective
Perform data cleaning and exploratory data analysis (EDA) on the Titanic dataset. Explore relationships between variables and identify patterns and trends in the data.

### What I Did
- Checked and handled missing values (Age filled with median, Embarked filled with mode, Deck column dropped)
- Explored survival patterns by Gender and Passenger Class
- Analyzed Age distribution
- Created a correlation heatmap to identify relationships between numeric variables

### Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

### Key Insights
- Females had a significantly higher survival rate than males
- Passengers in 1st class had better survival chances compared to 3rd class
